Entry for the make.fun bounty **u-rusdyxbt-one-letter-coffee-or-tea-89877fa0**
("One Letter: Coffee or Tea"). `main.py` writes exactly one letter — **A**
for coffee — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Coffee is the honest
answer: the letter A stands on its own as the whole reply, with no word,
no explanation and no punctuation beside it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt   # A
```
